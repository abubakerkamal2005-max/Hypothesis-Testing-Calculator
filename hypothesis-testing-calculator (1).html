Introduction to Hypothesis Testing

A statistical hypothesis is a claim about a parameter of one or more populations. Hypothesis testing is a structured way to weigh that claim against evidence from a sample.

Three methods, one procedure

Every test in this calculator can be run in equivalent ways — the critical value (traditional) method, the P-value method, or, for two-tailed tests, the confidence interval method — and they all lead to the same decision. Each follows the same five steps:

1
State H₀ and H₁ and identify the claim
2
Choose the test statistic and compute it
3
Find the critical value / rejection region (or the P-value)
4
Make the decision
5
Write the conclusion

Hypothesis Testing Using Confidence Interval

For a two-tailed test at significance level α, build the (1−α)×100% confidence interval for the parameter. H₀ is rejected exactly when the hypothesized value lies outside that interval. This equivalence holds for two-tailed tests only.

Hypothesis Testing for 1 Population Mean

Use the Z test when the population standard deviation σ is known. Use the T test when σ is unknown and is estimated by the sample standard deviation s.

Assumptions:
  • Random sample
  • Population approximately normally distributed (or n ≥ 30)

Hypothesis Testing Using the P-Value Method

The P-value is the probability, assuming H₀ is true, of getting a test statistic at least as extreme as the one observed. Reject H₀ when P-value ≤ α; otherwise, do not reject H₀.

H₀ / H₁ → Test statistic → P-value → Compare P-value with α → Decision → Conclusion
